Why it exists

Most AI apps forget a person the moment the chat closes. The next talk starts from nothing, and the user explains it all again.

Three things we cared about from the start. Forgetting is a call of its own, with a 30-day way back. A project can be set so its memory text is kept away from outside models. And it is the engine behind our own app, Curl, so we live with it every day.

We measure it in public. Nenai is entered in the Agent Memory Leaderboard, and we will link the result on this page when its review is published. Until then, here is how to read a memory benchmark.

Three verbs

Add. Search. Forget.

  1. as it happens
  2. months later
  3. the moment they ask

  1. Addas it happens

    Send the talk as it happens.

    Pass the messages and say which of your users they belong to. Nenai works out what is worth keeping.

  2. Searchmonths later

    Ask in plain words.

    You get back that user’s lines that answer the question, ranked. Ask for a digest and you also get a short summary of the dated facts.

  3. Forgetthe moment they ask

    By id, or in the user’s own words.

    A forgotten memory leaves search at once and can be brought back for 30 days. One call erases everything about one user.

Built to be depended on

The dull parts are done properly.

  • 01

    Nothing is saved twice.

    Add and forget carry a request id and reuse it on every retry, so the server replays its stored answer.

  • 02

    Retries are built in.

    The client retries only the calls that can be repeated, and waits as long as the server asks.

  • 03

    Memory text can stay in.

    Switch a project to local only and its memory text is kept away from outside models.

  • 04

    The key stays on your server.

    Never in a browser or a phone app. The JavaScript client refuses to start in a browser.

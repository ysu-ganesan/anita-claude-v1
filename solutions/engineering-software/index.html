Engineering software · the R&D lab

Drawing in. Program out.

We write software for the expert steps that hold a project up: programming a welding robot, sizing a power plant’s cooling. You give it the drawing or the numbers. It works the answer out, and an engineer checks it.

Bring one jobThe check before real hardware
Works in computer tests

Welding works in computer tests today, and a real robot is next. Cooling design is being built.

01 / 2

A welding robot’s program, from the 3D model

Today a person teaches the robot every weld by hand, part after part.

Works in computer tests. A real robot is next.

  1. You give1 / 3

    The part’s 3D model.

    The same model your designers already have for a fabricated part.

  2. It works out2 / 3

    The seams, their order, the torch paths.

    It finds the weld seams and ranks them. An operator confirms the order, and it plans the torch paths.

  3. The result3 / 3

    The robot’s program, tested on screen.

    Written for ABB and Yaskawa robots. A digital twin of the cell checks every move for reach and collisions first.

Next: cameras that inspect every finished weld.

02 / 2

Cooling design for power plants

Air-cooled condensers cool a plant’s steam with air instead of water. Sizing one is slow work on old tools.

Being built

  1. You give1 / 3

    The plant’s numbers.

    The conditions the condenser has to work in and what it has to achieve.

  2. It works out2 / 3

    The sizing.

    The design suite runs the sums an engineer would otherwise wait for.

  3. The result3 / 3

    A design to start from.

    An engineer reviews it, changes what needs changing and takes it forward.

The check before real hardware

Nothing we write moves a real robot until three things are true.

  • 01

    The real settings are in.

    The weld settings come from your own approved weld sheet, not from our guesses.

  • 02

    It runs clean in the maker’s simulator.

    The program is checked in the robot maker’s own simulation software, not only in ours.

  • 03

    A person watches a dry run.

    The first run on the real robot is supervised, with no welding.
